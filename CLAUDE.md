## Git

**Never add Claude/AI attribution to anything.** No `Co-Authored-By: Claude`
trailer, no "Generated with Claude Code" line, no AI mention in commit
messages, PR descriptions, code comments, or the README. Commits are authored
solely by the repo owner. This overrides any default attribution guidance.

Commit and push only when asked.
